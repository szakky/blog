# はじめに

こんにちは。

今回は、Windows PCにUbuntuを直接インストールしようとしたもののうまくいかず、代わりにProxmoxを導入したところ一発で環境構築できた体験について紹介します。

## なぜUbuntuにしようとしたか

新しくPCを購入したことがきっかけです。

以前使用していたPCは充電端子が故障してしまい、サーバー用途としても使えなくなってしまいました。また、以前からUbuntuを利用していたため、新しいPCでもUbuntuを使おうと考えていました。

実際にWindowsを2週間ほど使ってみたのですが、個人的にはフォルダ管理やコマンド操作がLinux環境の方が使いやすく感じたため、Ubuntuを導入することにしました。

# Ubuntu直インストール

まずは一般的な方法でUbuntuのインストールを試しました。

1. Ubuntu公式サイトからISOイメージをダウンロード
2. Rufusを使ってUSBメモリへ書き込み
3. USBメモリを挿した状態でPCを再起動
4. ブートメニューからUSBメモリを選択
5. 「Try or Install Ubuntu」を選択

ところが、「Try or Install Ubuntu」を選択した直後に画面が真っ黒になり、そのまま何分待っても進まなくなってしまいました。

## 試してみたこと

Linuxのインストール時によくあるトラブルを疑い、いくつかの対策を試しました。

### セキュアブートの無効化

BIOS設定画面から Secure Boot を無効化しました。

セキュアブートがインストーラの起動を妨げている可能性を考えたためです。しかし、症状は変わりませんでした。

### グラフィックドライバの回避（nomodeset）

ブートメニューで `e` キーを押し、起動オプションを以下のように変更しました。

```
変更前:
quiet splash

変更後:
nomodeset
```

これはGPUドライバの読み込みを回避し、最低限のグラフィック設定で起動させるための方法です。

GPUとの相性問題を疑って試しましたが、残念ながらこちらも改善しませんでした。

## なぜうまくインストールできなかったのか

現時点でも正確な原因は特定できていません。

ただし、セキュアブートやGPU関連の対策を行っても改善しなかったことから、以下のような可能性が考えられます。

- USBメモリの相性問題
- ISOイメージの破損
- Ubuntuインストーラとハードウェアの相性
- 起動時のグラフィック関連の問題

本来であればUSBメモリを交換したり、ISOイメージを再ダウンロードしたりしてさらに検証すべきでしたが、時間をかけるよりも別の方法を試してみることにしました。

そこで導入したのがProxmoxです。

# Proxmoxに切り替える

Proxmox VEは、1台の物理サーバー上で仮想マシン（VM）やコンテナを管理できるオープンソースの仮想化プラットフォームです。

導入方法はUbuntuとほぼ同じです。

1. Proxmox公式サイトからISOイメージをダウンロード
2. USBメモリへ書き込む
3. USBから起動
4. インストーラの手順に従ってインストール

インストール中にはネットワーク設定を行うため、設定したIPアドレスは控えておくことをおすすめします。

## なぜProxmoxならインストールできたのか

正確な原因は不明ですが、Ubuntu DesktopのインストーラではGPUやGUI周りの処理が必要になります。

一方、ProxmoxはGUI環境を必要とせず、比較的シンプルな構成で起動するため、今回の環境では問題なく動作した可能性があります。

そのため、Ubuntu Desktopの起動時に何らかの相性問題が発生していたのではないかと考えています。

## ProxmoxでUbuntuを作る

Proxmoxのインストール後は、Web管理画面から仮想マシンを簡単に作成できます。

UbuntuのISOイメージをアップロードし、仮想マシン作成ウィザードに従うだけで環境構築が完了します。

私もUbuntuの最新版をインストールし、無事にUbuntu環境を利用できるようになりました。

結果的には、当初の目的だった「Ubuntu環境を使う」という目標を達成できました。

# おわりに

今回はUbuntuを直接インストールしようとして失敗したものの、Proxmoxを導入することで無事にUbuntu環境を構築できました。

さらにProxmoxを導入したことで、Ubuntuだけでなく様々なOSやコンテナ環境を簡単に構築できるようになったのは予想外の収穫でした。

次回は、Proxmox上に構築したサーバーでWebカメラから送られたデータを受信し、そのデータを外部へ公開する仕組みについて紹介したいと思います。
